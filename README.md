# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 每格两层

- 每个格子最多容纳两层：空格先放底字，再在底字上叠一枚小一号的强调字，后放的在上面。
- 底字和上层分别占用字模库存；同一件字模不能叠在自己上面。
- 上层字号大于底字，或字模数量不够时，格子保持原样，画布上方会说明原因。
- 再点一次最上层的字模可撤掉上层；格子已有两层时选别的字模落字即切换上层。
- 两层的内容和顺序随草稿保存、随导出 PNG 保留；旧草稿的单字格子仍按单层打开。
